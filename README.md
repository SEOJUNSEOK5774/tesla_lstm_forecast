# Tesla_Lstm_Forecast

# Tesla Open Price Prediction with LSTM

### 1. プロジェクト概要

このプロジェクトは、Tesla（TSLA）の過去の始値データを学習し、次の取引日の始値を予測するLSTMベースの株価予測プロジェクトです。

直近60取引日の始値を1つの入力データとして使用し、複数のLSTM層で構成されたニューラルネットワークによって予測値を生成します。

### 2. 主な機能

- Teslaの株価CSVデータの読み込み
- 始値（Open）の正規化
- 直近60取引日を使用した学習データの作成
- 多層LSTMモデルの学習
- テスト期間の株価予測
- 実際の価格と予測価格のグラフ比較
- 日付を基準とした可視化

### 3. プロジェクト構成

```text
tesla-stock-prediction/
├── tesla_open_price_lstm_ja.py
├── Tesla_Stock_Price_Train.csv
├── Tesla_Stock_Price_Test.csv
└── README.md
```

可能であれば、3つのファイルを同じフォルダーに配置してください。

### 4. データ構成

CSVファイルは次の列で構成されています。

| 列名 | 説明 |
|---|---|
| Date | 取引日 |
| Close | 終値 |
| High | 高値 |
| Low | 安値 |
| Open | 始値 |
| Volume | 出来高 |

このプロジェクトでは、モデルの学習に `Open` 列のみを使用します。

- 学習データ：2018-01-02 ～ 2023-12-29
- テストデータ：2024-01-02 ～ 2025-08-01
- 入力シーケンス：直近60取引日
- 予測対象：次の取引日の始値

### 5. 必要なライブラリ

次のコマンドで必要なパッケージをインストールします。

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow keras
```

### 6. 実行方法

ターミナルでプロジェクトフォルダーに移動し、次のコマンドを実行します。

```bash
python tesla_open_price_lstm_ja.py
```

Windows環境では、次のコマンドも使用できます。

```bash
py tesla_open_price_lstm_ja.py
```

### 7. モデル構成

モデルは次のように構成されています。

- LSTM層：4層
- 各LSTM層のユニット数：50
- Dropout率：0.2
- 出力層：Dense 1層
- 最適化アルゴリズム：Adam
- 損失関数：Mean Squared Error
- エポック数：10
- バッチサイズ：32

### 8. 実行結果

モデルの学習が完了すると、次の2つの値がグラフに表示されます。

- 赤色：Teslaの実際の始値
- 青色：LSTMモデルが予測した始値

### 9. 注意事項

このモデルは、テスト期間における実際の過去の始値を使用して、次の取引日の値を予測します。そのため、未知の長期的な将来価格を連続して予測するモデルとは異なります。

予測結果は、エポック数、モデル構造、データ期間、およびランダムな初期値によって変化する場合があります。

このプロジェクトは学習・研究目的で作成されたものであり、実際の投資判断を目的とした金融アドバイスではありません。
